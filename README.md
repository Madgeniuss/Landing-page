# Shadows of Sicily 📸

A modern, minimalist photography portfolio showcasing the timeless streets, beautiful architecture, and sunlit landscapes of Sicily, Italy.

## 🌐 About the Project

**Shadows of Sicily** is a photography portfolio website built to practice HTML and Tailwind CSS. The design focuses on clean typography, elegant spacing, responsive layouts, and subtle hover effects to create a premium visual experience.

## ✨ Features

- Minimalist and modern design
- Responsive layout for different screen sizes
- Navigation with smooth hover effects
- Photography gallery with responsive image grids
- Project details and photography descriptions
- Clean typography and spacing
- Tailwind CSS utility classes for styling

## 🛠️ Technologies Used

- **HTML5** — Website structure
- **Tailwind CSS** — Styling and responsive design
- **Git & GitHub** — Version control and project hosting

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Open the project

Navigate to the project folder:

```bash
cd shadows-of-sicily
```

### 3. Run the website

Open `index.html` in your browser.

If you are using the Tailwind CSS browser CDN, make sure it is included in the `<head>` section of your HTML file.

This project helps practice:

- Semantic HTML elements
